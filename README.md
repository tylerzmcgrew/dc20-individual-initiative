# DC20 - Individual 5e Initiative

A Foundry VTT module for the **DC20 RPG** system (`dc20rpg`) that changes combat initiative to individual d20 rolls per actor, similar to D&D 5e.

**Version 1.0.0** · Foundry VTT V14

## What it does

- Rolls initiative per combatant with `1d20 + Agility + Combat Mastery`.
- Optional setting to automatically reroll initiative for everyone at the start of each round.
- Adjusts the combat tracker to work with individual initiative.

## Installation

In Foundry, go to **Add-on Modules → Install Module** and paste this into **Manifest URL**:

```
https://github.com/tylerzmcgrew/dc20-individual-initiative/releases/latest/download/module.json
```

Enable **DC20 - Individual 5e Initiative** in a world that uses the DC20 system.

## Settings

| Setting | Description | Default |
| --- | --- | --- |
| Reroll Initiative Each Round | Rerolls initiative for all combatants at the start of a new round. | Off |
